# ☕ Brew & Bean Cafe - Multi-Page Website

A responsive 6-page cafe website built using **HTML5, CSS3 and JavaScript** (no frameworks).

## Pages
| Page | File | Highlights |
|------|------|-----------|
| Home | `index.html` | Hero, today's special (Date object), bestsellers, counters, testimonial slider |
| About | `about.html` | Story, values, timeline, team (JS array) |
| Menu | `menu.html` | Search, category filter, price sorting, add to order |
| Order | `order.html` | Cart with quantity controls, coupon codes, GST, checkout validation |
| Gallery | `gallery.html` | Image grid with lightbox (arrow keys + Esc) |
| Contact | `contact.html` | Form validation, character counter, FAQ accordion |

## Concepts used
- **HTML:** semantic tags, forms, attributes (`id`, `class`, `data-*`, `title`), links between pages
- **CSS:** variables, Flexbox, Grid, transitions, animations, media queries, dark mode
- **JavaScript:** arrays/objects, loops, functions, conditions, DOM manipulation, events, `setInterval`/`setTimeout`, `Date`, regex validation, `localStorage`

## Try these
- Coupon codes: `BREW10` (10% off), `STUDENT15` (15% off)
- Toggle 🌙 dark mode (it is remembered)
- The cart is shared across pages using localStorage

## Run locally
Download or clone the repo and open `index.html` in any browser.
